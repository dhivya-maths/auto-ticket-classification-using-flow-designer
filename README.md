# Auto Ticket Classification Using Flow Designer

## Project Description
This project is designed to automatically classify support tickets using ServiceNow Flow Designer.

## Objective
The main objective of this project is to automate the ticket classification process and reduce manual work.

## Technologies Used
- ServiceNow
- Flow Designer

## Features
- Automatic ticket classification
- Automated workflow
- Ticket routing
- Reduced manual effort

## Project Implementation
The project is implemented using Flow Designer in ServiceNow. The flow processes the incoming ticket and performs the required actions automatically.

## Conclusion
This project demonstrates how Flow Designer can be used to automate ticket classification and improve the efficiency of ticket management.
